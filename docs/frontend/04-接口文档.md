# FastTunnel 管理面板 — 前端接口文档

---

## 一、接口通用约定

### 1.1 Base URL

```
/api
```

### 1.2 通用响应格式

```ts
interface ApiResponse<T = unknown> {
  /** 请求是否成功 */
  success: boolean
  /** 响应数据 */
  data: T
  /** 提示消息 */
  message: string
}
```

### 1.3 认证

除 `/api/account/token` 外，所有接口需携带 JWT：

```
Authorization: Bearer <token>
```

### 1.4 通用状态码

| HTTP Status | 含义 | 前端处理 |
|-------------|------|----------|
| 200 | 成功 | 检查 `response.success`，`false` 时 toast `message` |
| 401 | Token 过期/无效 | 清除登录态，跳转 `/login` |
| 500 | 服务端异常 | toast "服务器内部错误" |

### 1.5 分页参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `page` | number | 1 | 页码 |
| `pageSize` | number | 20 | 每页条数 |

## 二、系统初始化接口

```
权限: 无需认证 (未初始化状态)
```

### 2.1 GET /api/setup/status

查询系统是否已完成初始化。

**Response (未初始化):**

```json
{
  "success": true,
  "data": { "initialized": false },
  "message": null
}
```

**Response (已初始化):**

```json
{
  "success": true,
  "data": { "initialized": true },
  "message": null
}
```

**前端实现:**

```ts
// api/setup.ts
import request from './request'
import type { ApiResponse } from '@/types/api'

interface SetupStatus {
  initialized: boolean
}

export function getSetupStatus() {
  return request.get<ApiResponse<SetupStatus>>('/setup/status')
}
```

### 2.2 POST /api/setup/init

首次部署时创建管理员账号。**系统已初始化后此接口返回 403**。

**Request Body:**

```json
{
  "name": "admin",
  "password": "MyPass123"
}
```

| 字段 | 必填 | 规则 |
|------|------|------|
| `name` | ✅ | 3-64 字符 |
| `password` | ✅ | ≥ 8 位，含字母 + 数字 |

**Response (成功):**

```json
{
  "success": true,
  "data": null,
  "message": "初始化完成"
}
```

**Response (密码过弱):**

```json
{
  "success": false,
  "data": null,
  "message": "密码强度不足：至少 8 位，包含字母和数字"
}
```

**Response (已初始化后调用):**

```json
{
  "success": false,
  "data": null,
  "message": "系统已完成初始化，请使用 /api/account/token 登录"
}
```

HTTP Status: 403

**前端实现:**

```ts
// api/setup.ts
interface SetupInitRequest {
  name: string
  password: string
}

export function initSystem(data: SetupInitRequest) {
  return request.post<ApiResponse<null>>('/setup/init', data)
}
```

## 三、认证接口

### 3.1 POST /api/account/token

登录获取预认证令牌。账号密码校验通过后，根据 MFA 绑定状态返回不同结果。

```
权限: 无需认证
```

**Request Body:**

```json
{
  "name": "admin",
  "password": "admin123"
}
```

**Response — MFA 未绑定 (首次登录):**

```json
{
  "success": true,
  "data": {
    "requiresMfa": true,
    "mfaBound": false,
    "preAuthToken": "eyJhbGciOiJIUzI1NiIs...",
    "username": "admin"
  },
  "message": null
}
```

**Response — MFA 已绑定:**

```json
{
  "success": true,
  "data": {
    "requiresMfa": true,
    "mfaBound": true,
    "preAuthToken": "eyJhbGciOiJIUzI1NiIs...",
    "username": "admin"
  },
  "message": "请输入 MFA 验证码"
}
```

**Response — 凭据错误:**

```json
{
  "success": false,
  "data": null,
  "message": "用户名或密码错误"
}
```

| 字段 | 说明 |
|------|------|
| `requiresMfa` | 始终为 `true`（MFA 强制开启） |
| `mfaBound` | `false`=未绑定需设置 / `true`=已绑定需验证 |
| `preAuthToken` | 临时 JWT，仅可调用 MFA 系列接口，有效期 5 分钟 |
| `username` | 登录用户名 |

**前端实现:**

```ts
// api/auth.ts
import request from './request'
import type { ApiResponse } from '@/types/api'

interface LoginRequest {
  name: string
  password: string
}

interface LoginResponse {
  requiresMfa: true
  mfaBound: boolean
  preAuthToken: string
  username: string
}

export function login(data: LoginRequest) {
  return request.post<ApiResponse<LoginResponse>>('/account/token', data)
}
```

### 3.2 MFA 系列接口

```
权限: Bearer preAuthToken (POST /api/account/token 返回的临时令牌)
```

#### 3.2.1 POST /api/account/mfa/setup

生成 TOTP 密钥与二维码。**仅 MFA 未绑定时可调用。**

**Response:**

```json
{
  "success": true,
  "data": {
    "secret": "JBSWY3DPEHPK3PXP",
    "qrCodeUrl": "otpauth://totp/FastTunnel:admin?secret=JBSWY3DPEHPK3PXP&issuer=FastTunnel"
  },
  "message": null
}
```

| 字段 | 说明 |
|------|------|
| `secret` | Base32 编码的 TOTP 密钥，供手动输入 |
| `qrCodeUrl` | `otpauth://` 标准 URL，前端可用 `qrcode` 库渲染为二维码图片 |

**错误 (已绑定):**

```json
{
  "success": false,
  "data": null,
  "message": "MFA 已绑定，无需重新设置"
}
```

**前端实现:**

```ts
// api/mfa.ts
import request from './request'

interface MfaSetupResponse {
  secret: string
  qrCodeUrl: string
}

export function setupMfa(preAuthToken: string) {
  return request.post<ApiResponse<MfaSetupResponse>>(
    '/account/mfa/setup',
    null,
    { headers: { Authorization: `Bearer ${preAuthToken}` } },
  )
}
```

#### 3.2.2 POST /api/account/mfa/bind

首次绑定 MFA：校验 TOTP 验证码并绑定。成功后返回完整 JWT。**仅 MFA 未绑定时可调用。**

**Request Body:**

```json
{
  "code": "123456"
}
```

| 字段 | 必填 | 规则 |
|------|------|------|
| `code` | ✅ | 6 位数字 |

**Response (成功):**

```json
{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "username": "admin"
  },
  "message": "MFA 绑定成功"
}
```

**Response (验证码错误):**

```json
{
  "success": false,
  "data": null,
  "message": "验证码错误，请重试"
}
```

| 字段 | 说明 |
|------|------|
| `token` | 完整权限 JWT，之后所有接口使用此 Token |
| `username` | 用户名 |

**前端实现:**

```ts
export function bindMfa(code: string, preAuthToken: string) {
  return request.post<ApiResponse<{ token: string; username: string }>>(
    '/account/mfa/bind',
    { code },
    { headers: { Authorization: `Bearer ${preAuthToken}` } },
  )
}
```

#### 3.2.3 POST /api/account/mfa/verify

验证 TOTP 验证码并返回完整 JWT。**仅 MFA 已绑定时可调用。**

**Request Body:** 同 `/api/account/mfa/bind`

**Response (成功):**

```json
{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "username": "admin"
  },
  "message": null
}
```

**Response (验证码错误):** 同 bind 错误响应。

**前端实现:**

```ts
export function verifyMfa(code: string, preAuthToken: string) {
  return request.post<ApiResponse<{ token: string; username: string }>>(
    '/account/mfa/verify',
    { code },
    { headers: { Authorization: `Bearer ${preAuthToken}` } },
  )
}
```

**preAuthToken 全局错误：**

| 条件 | HTTP Status | message |
|------|-------------|---------|
| preAuthToken 过期 | 401 | "预认证令牌已过期，请重新登录" |
| preAuthToken 无权访问非 MFA 接口 | 403 | "权限不足" |
| 已绑定后调用 setup/bind | 400 | "MFA 已绑定" |
| 未绑定时调用 verify | 400 | "请先绑定 MFA" |

## 五、Web 隧道接口

### 4.1 GET /api/tunnels/webs

获取所有 Web 隧道列表。

**Query Parameters:**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `subDomain` | string | 否 | 按子域名模糊搜索 |
| `clientId` | number | 否 | 按客户端 ID 过滤 |
| `isEnabled` | boolean | 否 | 按启用状态过滤 |
| `page` | number | 否 | 页码 |
| `pageSize` | number | 否 | 每页条数 |

**Response:**

```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "subDomain": "api",
      "localIp": "192.168.1.100",
      "localPort": 8080,
      "wwws": ["api.example.com"],
      "clientId": 1,
      "clientName": "办公室服务器",
      "isEnabled": true,
      "createdAt": "2026-05-01T10:00:00Z"
    }
  ],
  "message": null
}
```

### 4.2 POST /api/tunnels/webs

新增 Web 隧道。

**Request Body:**

```json
{
  "subDomain": "api",
  "localIp": "192.168.1.100",
  "localPort": 8080,
  "wwws": ["api.example.com"],
  "clientId": 1
}
```

**Response:**

```json
{
  "success": true,
  "data": {
    "id": 2,
    "subDomain": "api",
    "localIp": "192.168.1.100",
    "localPort": 8080,
    "wwws": ["api.example.com"],
    "clientId": 1,
    "isEnabled": true,
    "createdAt": "2026-05-15T08:30:00Z"
  },
  "message": "隧道创建成功"
}
```

**校验规则：**

| 字段 | 必填 | 规则 |
|------|------|------|
| `subDomain` | ✅ | 1-63 字符，仅字母数字连字符 |
| `localIp` | ✅ | 合法 IPv4 地址 |
| `localPort` | ✅ | 1-65535 |
| `wwws` | ❌ | 每个元素为合法域名 |
| `clientId` | ✅ | 已存在的客户端 ID |

### 4.3 PUT /api/tunnels/webs/{id}

修改 Web 隧道。

**Request Body:** 同 POST，字段均可选传。

**Response:** 同 POST。

### 4.4 DELETE /api/tunnels/webs/{id}

删除（软删）Web 隧道。

**Response:**

```json
{
  "success": true,
  "data": null,
  "message": "隧道已删除"
}
```

### 4.5 PATCH /api/tunnels/webs/{id}/toggle

切换启用/禁用状态。

**Request Body:**

```json
{
  "isEnabled": false
}
```

**Response:**

```json
{
  "success": true,
  "data": { "id": 1, "isEnabled": false },
  "message": "隧道已停用"
}
```

## 十一、前端 Axios 拦截器处理矩阵

| 场景 | 拦截器行为 |
|------|------------|
| 请求发送 | 从 `useAuthStore().token` 注入 `Authorization` 头 |
| preAuthToken 请求 (MFA) | 前端手动传 `Authorization: Bearer <preAuthToken>`，这些请求绕过 store 的 token |
| 响应 `success: false` | `Message.error(message)` |
| 响应 `success: true` | 返回 `response.data` |
| HTTP 401 (preAuthToken 过期) | Toast "预认证令牌已过期，请重新登录"，回到登录表单阶段1 |
| HTTP 401 (完整 JWT 过期) | 清除登录态，跳转 `/login` |
| HTTP 403 | `Message.error(message)` |
| 网络超时 (10s) | `Message.error("请求超时")` |
| 其他网络错误 | `Message.error(error.message)` |
